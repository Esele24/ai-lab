Why the A/B test shuffles the order

A model asked to judge two outputs has two measurable biases: it prefers the longer answer, and it prefers whichever it was shown first. A naive comparison inherits both and calls it a result.

So this one shuffles which real output is labelled "A" before the judge sees them, scores against four named criteria instead of "which is better", and prints each output's word count beside its score — so you can see for yourself when a win is really just verbosity.

Even with that, a judge is a filter, not a verdict. Read the outputs.
