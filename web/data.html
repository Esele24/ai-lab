Why this does not ask the model to write pandas code

The obvious build is “have the model write pandas, then exec() it”. That is how most demos do it, and it is two bad things at once: a remote-code-execution hole, and a liar — when its own code errors the model will happily state a number anyway.

Here the model returns a structured operation under a strict responseSchema at temperature 0 — which column, which aggregation, which filters, which chart. Pandas does the arithmetic. A second call writes the sentences, and is given only the computed result, never the raw data.

The consequence worth stating: the model cannot report a total that pandas did not compute. Its worst available failure is picking the wrong column — which is visible, because the chosen operation is shown beside every answer.
