06Industry-Specific AI Helper

Review a document against the clauses that industry expects to see — so it can report what is missing. That is the finding a general chatbot structurally cannot make, because it only reacts to text that is there.

Drop a contract or click

Checklist

Every item is assessed, including the ones the document does not mention.

Three guarantees

  1. temperature 0 — the same document gives the same review.
  2. Strict response schema — output is a shape, not prose to parse.
  3. Quote verification — after the model answers, every finding's quote is checked against the actual document text. Anything it cannot show is dropped or demoted to ABSENT before it reaches this screen. A finding citing a clause the document does not contain is worse than no finding: it is the one you would act on.

What this is not

It is not legal advice, and it does not replace a lawyer reading the contract. It is a first pass that tells you which clauses to go and look at — the value is in the ABSENT rows.
