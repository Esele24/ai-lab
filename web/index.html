04The full AI-powered app

Seven AI projects sharing one backend, one model client, one database and one design system. This dashboard is project 04 — not a landing page for the others, but the application they live inside. Every number below is read from disk.

The tools

Activity log

Written to data/ai_lab.db by every tool, and read back here. It survives restarting the server — which a variable in memory would not.

What is actually running

The model

There is no OpenAI key and no Anthropic key on this machine. The project list this was built from assumed OpenAI; this runs on the key that exists and works, called over plain HTTPS in core/gemini.py.

A 429 whose body says limit: 0 means the model name is wrong for the key — not that you are being rate limited.

The dependencies

Backend: http.server, sqlite3, numpy, pandas, pypdf, python-docx, requests. Frontend: none.

No Flask, no Streamlit, no scikit-learn, no chart library, no CDN. Partly a constraint — a 36 MB scipy wheel would not finish downloading — and partly the point: the classifier in project 03 is written out by hand instead of imported.
